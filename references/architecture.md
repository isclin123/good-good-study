# 持续学习项目架构

## 从可用教学开始

结构服务于课程规模。先完成学习目标、路线、角色、真实活动记录和恢复入口，再扩展题库、自动测评、媒体或界面。单次指导可直接进行；持续课程落地为可跨对话恢复的本地项目。

推荐本地文件与 SQLite，优先标准库和少量稳定依赖。语言与实现工具按环境选择。保存的记忆可由不同模型读取，基础查询、复习、备份和统计可离线运行。

## 目录职责

按实际规模合并模块，覆盖以下职责：

```text
project/
  AGENTS.md
  README.md
  PROJECT_STATE.md
  config/             # 目标、角色、记忆绑定、对话登记
  agents/             # 角色职责与启动提示
  memory/             # schema、迁移、上下文、检索
  data/               # SQLite、媒体、作品、备份
  curriculum/         # 路线、先修关系、完成标准
  exercises/          # 练习任务与检查点
  assessment/         # 量规、反馈、统计、复习
  orchestration/      # 队列、交接、计划版本
  reports/
  scripts/            # 初始化、启动、导出、备份、恢复
  docs/
  tests/
```

## 四层数据

- Core：目标、偏好、能力信息与候选，区分事实、推断、待确认。
- Episodic：真实学习活动、输入或作品、反馈、量规、时间与来源。
- Semantic：知识技能、先修关系、错误模式、资源与复习历史。
- Working：当前计划、暂停点、未完成任务与角色交接。

数据库为权威，状态摘要与报告可重建。原始产物按路径和证据 ID 关联。结构化查询、标签与全文检索先保证可用；中文等语言验证分词，并提供适当检索回退。

## 一致性

每个课程有持久 project_id；多课程共享数据库时，唯一约束、外键、检索、统计与队列都按课程隔离。记录真实发生时间和录入时间，未知值保持未知。

原始输入保留，反馈和修正另存。事件键与载荷校验使重试幂等；修正有审计。多个角色使用独立连接、短事务、外键、busy timeout、WAL 与原子任务领取。

schema 版本化；迁移和恢复使用一致性备份。私人数据默认保存在本地。

## 自适应策略

围绕课程目标定义掌握证据：理解、独立性、操作质量、保持、迁移或作品质量。

复习优先级综合到期程度、重复困难、先修重要性、目标期限和已有保持证据。用简单可解释的规则起步，记录每次调整的理由。复习间隔可从1、3、7、14天开始并按实际表现调整。

提示依赖与独立完成分别记录。安排专项训练时保留其他模块覆盖。开放性任务用适当量规评估选择、过程和改进。

## 入口能力

实现规模与课程匹配，持续项目至少支持：

- 初始化、诊断、状态与学习计划。
- 角色上下文、练习、保存与暂停恢复。
- 复习、历史、检索、报告与人工修正。
- 交接队列及任务领取、完成和失败重试。
- 备份、导出、schema 迁移与受控恢复。

命令名和参数按实际实现写入指南。先验证最小保存链并开始教学，再逐步补充扩展功能。

## 验收重点

使用临时数据检查记录读写、未知信息语义、合理替代答案、修正审计、复习调度、幂等重试、并发完整性、课程隔离、交接恢复及备份。

验证完整链：专项保存结果 → 新测评进程读取 → 新总控进程调整 → 新专项进程接续。合成测试数据只进入临时库。

完成后的可观察结果：关闭对话后再进入，系统可读取用户已学内容、具体困难、当前暂停点、到期复习和各角色的下一任务。
